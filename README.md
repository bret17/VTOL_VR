Traduction du jeu VTOL VR en français. Compatible avec la version 1.13.3 du jeu.

Bonjour.

Cette traduction a été réalisée pour aider les joueurs qui ont plus de mal avec l’anglais. Elle n’a pas pour vocation d’être parfaite, mais plutôt d’être fonctionnelle, complète et suffisamment claire pour permettre de profiter pleinement du jeu.

Tout le monde peut participer à l’amélioration de cette traduction.

Cette traduction s’appuie sur le travail de Keno, merci à lui :)
